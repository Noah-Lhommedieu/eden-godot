# Lot — Rachat boutique (buyback) natif

## Symptômes

- `ShopHandlers.cs:33` : branche `msg.Count != 0` du paquet buy
  (NCID 22) = TODO → rachat impossible.
- `CNC_CZ_ClientBuyBackList` généré = record plat de 46 champs émis
  **une fois** (corps ~80 o même vide) — hors spec : le natif envoie
  `[u8 flag][u16 n]` puis n records + s16 terminal.
- La file buyback actuelle est une queue de `(itemId, qty, prix)`
  cap 12 — pas de snapshot des attributs (sockets/combo/enchant
  perdus au rachat), ordre inversé vs natif.

## Preuves natives (désasm zone+mission)

- `CNE_CZ_ZoneServerBuyItems::Execute` @0x823f1b0 : wire
  `[u16 slot/index][u16 count][u8 flag]` — flag≠0 →
  `CItemFactory::BuyBackItems(char, u16 index)` @0x8092cd0 :
  op shop (type 0x21) à portée, index < taille deque → serial =
  deque[index] → `CItemDBO::GetBuyBackItem` (texte 0x5f5 si index
  hors bornes), flag `char+0x604` anti double-achat.
- `CNC_CZ_ClientBuyBackList::Serialize` @0x8344xxx (zone) :
  `[u8 flag][u16 n]` + **36 vecteurs parallèles** + `s16` terminal
  (+0x17c, = -1 à l'ouverture) :
  u16 item_id, s16 durability, s16 identify, s16 f3, s16 f4,
  u8 embedded_amount, 6×s16 embedded_id1-6, s16 witchcraft/combo,
  string maker, 11×s16 extra_combo_id1-11, 2×s16 (strengthen,
  cur_maxdurability), i64 due_date, CEquipTrainAttrs (20 o),
  s16, u32 **price**, s16, 2×s16, u16, u16.
  (Remise mission→zone→client : 1 vecteur de queue non forwardé,
  champs de queue ~0 pour les items courants.)
- `CNE_CZ_ZoneServerBuyBackOpen` (NCID 185) `[u8 flag]` :
  Execute @0x823ebxx — capture le shop courant (op type 0x21) puis
  exécute `shop buy_back <id> <arg>` → envoi d'un
  ClientBuyBackList **vide** flag=3 ; la liste remplie arrive via
  ZMis (mission).
- Stockage natif : **mémoire session côté mission** — pas de table
  SQL (aucune dans fndb1 ; « Temp UID » libéré à la déconnexion).
  Deux deques parallèles (serials + prix), trim à **10** entrées
  (`while (10 < size) pop_front` dans l'Execute ZMis).
- Prix de rachat = `total_price` passé à `Sell Item` (le montant
  reçu à la vente — text-command `CItemDBO::SellItem` @0x8355dxx).
- Vente : `EradicateItem(..., param_6=true)` → `CItemDBO::SellItem`
  « Sell Item loc= %hd id= %d container_index= %hd total_price= %d ».

- `ShopService` : `BuybackEntry` = snapshot `ItemEntity` + prix ;
  deque cap 10 (trim front) ; ordre insertion (natif).
  `BuyBackItemAsync(charId, index)` : index borné → or ≥ prix →
  débit → restore item (attributs snapshot) → retrait entrée.
- `InventoryService.RestoreItemAsync(entity)` : slot libre + insert
  avec sockets/combo/enchant/dates du snapshot (pas de re-roll).
