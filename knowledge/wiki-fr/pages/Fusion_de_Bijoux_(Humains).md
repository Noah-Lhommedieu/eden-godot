# Fusion de Bijoux (Humains)

> Source : `raw/wiki-fr/Fusion_de_Bijoux_(Humains).html` (fandom FR)

La fusion de bijoux est l'artisanat de race des humains qui leur permet de créer des gemmes afin de les sertir dans les armes et armures.
Les matériaux peuvent être collectés dans les mines, les potagers et les sources d'énergie dans n'importe quelle ville de guilde. Chaque type de collecte donne 2 matériaux au niveau 30 (un blanc et un vert), puis un type supplémentaire à partir du niveau 45.
## Liste des bonus
  * Potager :

  *     * Matériau blanc : HP + un bonus parmi : défense / blocage / parade / HP (double le bonus)
    * Matériau vert : MP + un bonus parmi : défense / blocage / parade / MP (double le bonus)
  * Mine :

  * Matériau blanc : FOR + un bonus parmi : ATQ PHY / blocage / défense / +2 FOR
    * Matériau vert : AGI + un bonus parmi : Parade / VIT INV / VIT ATQ / +2 AGI
  * Source d'énergie :

  * Matériau blanc : INT + un bonus parmi : ATQ MAG / Taux de CRIT MAG / DEG CRIT MAG / +2 INT
    * Matériau vert : SAG + un bonus parmi : Défense / Guérison Générale / Guérison Perso / +2 SAG
  * Matériaux oranges :

  *     * Niveau 30 : CHA + un bonus parmi : PREC / Taux de CRIT / Taux de CRIT MAG / +2 CHA
    * Niveau 60 : un bonus parmi : XP / PC / Drop / Toutes résistances +1%
