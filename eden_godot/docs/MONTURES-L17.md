# Montures — position/orientation d'attache du cavalier (nœud `L17`)

## Source et sémantique (natif)

`CRide::Attach` (rf_game `FUN_0073fc60`, `re/ghidra/rf_game/decompiled.c:677628`) :

1. le transform du cavalier est copié sur la monture (`+0x30..+0x60`, 13 dwords : rotation 3x3, translation, scale) ;
2. le transform LOCAL du cavalier est remis à l'identité (`DAT_00fdf368` = matrice identité 9 floats, translation `DAT_01055914..1c` = 0, scale `0x3f800000` = 1.0) ;
3. `FUN_00731ba0(&"L17" (DAT_00f069f4), cavalier, 1, 0)` → `FUN_00731320` : cherche le nœud nommé `L17` dans le modèle de la monture et y accroche le cavalier comme **enfant** (`vtbl+0x88`, drapeaux `1,0` = attache sans vider les enfants existants du nœud et sans flag supplémentaire).

Conséquence : la **racine** du cavalier (pieds, origine du NIF perso) prend le transform monde COMPLET de `L17` (position + rotation, animés avec la monture : `L17` est enfant de `Bip01 Spine` et porte même des pistes d'anim `stand01/move01` dans `ride/animation/*.glb`). Passagers : `L%d` (siège+0x32 / +0x3c, `FUN_0073f150`, format `PTR_00f06ed4`) = `L51/L52…`, `L61/L62…`.

Il n'existe AUCUNE autre table de placement :
- `ridelist.ini` : col 2/3 = scale (1.00 sauf quelques variantes, ex. r521 0.5/2.0) ; col 5/6 = `0.0;0.0;0.0` sur les 415 lignes ; col 9 = classe de taille (réfutée comme hauteur de selle) ; col 7/8/10 constantes.
- `c_ridestep.ini` = sons de pas, `boundinfo.ini` = monstres (aucune monture).
- `B.kf` (anims cavalier `ride01-08`) : AUCUNE translation de bassin (`Bip01` = pose statique 0 ; `Bip01 Pelvis` = 2 clés de rotation nulles) → le natif ne rabaisse pas le cavalier : ses hanches (~0,45 au-dessus de la racine, jambes pliées par ride01 : calf 83°) sont au-dessus de `L17`. Les concepteurs ont donc placé `L17` sous la surface de selle.

## Implémentation client

Même code pour le joueur local (`MissionBridge.SetRideModel`), les entités distantes (`EntityRegistry.SetRide`) et l'aperçu (`ItemPreviewWindow`). Repli statique (`RideFit.Apply`) pour les modèles sans `L17` exploitable.

Repère des valeurs ci-dessous = repère GLB (Z-up, avant −y = tête) de l'état de repos, avant la rotation d'import ; quaternion `(x, y, z, w)` = rotation monde de `L17` au repos ; « angle » = écart à l'identité. Colonne scale = `ridelist.ini` col 2 (par variante). `—` = repère identité.
