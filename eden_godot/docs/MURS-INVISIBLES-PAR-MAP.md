Genere par `python3 tools/walls_report.py --raw <overlay EDENFR> --md ...`
(2026-10-31). Deux familles, TOUTES appliquees a toutes les maps :

1. **Grille native `sknodemap/Sxxx.smp`** (cases de 0,5 u, bit0 = obstacle) :
   client `NodeMapFile` + `PlayerController.ClipByNodeMap` (glissement par axe),
   serveur `Eden.Core.Game.Services.NodeMapGrid` + validation dans
   `ZoneEntryFlow.HandleMoveSelfAsync` (refus = ClientResetCoord ; entree dans
   une case obstacle depuis une case libre uniquement ; kill-switch
   `EDEN_NODEMAP=0`, dossier `NODEMAP_DIR`, defaut `Data/NodeMap`).
2. **Meshes helper** (`true wall`, `block`, `camera`, `blo`, `knock`, `Line`)
   dans les NIF (objets du .fsm + NIF de map entiere) : `CollisionBuilder`
   (StaticBody3D layer 1) - colonnes « Modeles/Instances helper ».

Colonnes : % = part de cases bloquees (zones hors parcours incluses, comme le
natif) ; « isolees » = cases bloquees sans voisine (piliers, troncs).
