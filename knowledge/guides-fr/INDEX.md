# Guides Eden Eternal (edenfr.wordpress.com) — Index

Index des **guides français** du site WordPress edenfr.wordpress.com (`raw/guides-fr/`, articles 2015-2018 + pages sommaires). Site communautaire **Vendetta** : les guides mélangent jeu de base et contenu custom dans une même page — chaque ligne est marquée quand c'est le cas.

Chaque article a été converti en markdown dans `pages/`. Les images des pages d'attachement (`wp-content/`) ont été téléchargées dans `images/` et les liens qui y menaient pointent vers ces copies locales (`../images/<fichier>`). Les autres images restent des URL distantes — motifs : `edenfr.wordpress.com/wp-content/uploads/…` (souvent relayé par le proxy `i0/i1/i2.wp.com`), captures externes `farm*.staticflickr.com`, `puu.sh`, `vendettagn.com`.

**Dans le périmètre (≤90)** : donjons régionaux 1-80 + héroïques HQ50-90 (runs détaillés), classes normales (prérequis, certificats, expertise, sorts 72), éveil armes 65/75 + armures 70/80, artisanat racial 5 races, monde d'Ezur (Aven, gloires, cristaux d'Asbi, world boss), systèmes (couple, familiers, villa, boîte mystique, météores, métamorphoses), PvP (territoire, élimination), monnaies, montures, costumes.

**Périmètre serveur** : notre serveur réplique l'Eden de base (contenu jusqu'au niveau 90). Tout le contenu **niveau 95+** et les exclusivités du serveur privé **Vendetta** (classes Dragon Soul/Emperor, Luminary, Mimic, 4Trial, Gates of Pandemonium, HQ 95/100, armures éveillées 95, patchs VGN…) sont **hors périmètre** — voir la section dédiée en bas. Pages **mixtes** (sections ≤90 + sections >90) marquées « partiellement hors périmètre » — seules les parties haut niveau sont à écarter.
