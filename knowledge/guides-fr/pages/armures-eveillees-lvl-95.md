# Armures éveillées Lvl 95

> Source : `raw/guides-fr/2017/05/31/armures-eveillees-lvl-95.html` — publié le 2017/05/31 (site WordPress edenfr.wordpress.com)

Les sets éveillés 95 sont une création exclusive du serveur **Vendetta**. Ils n’existent ni sur le serveur Aeria ni dans les versions asiatiques du jeu. Il n’est pas nécessaire d’avoir fait les sets 70 et 80 précédents. En revanche, le prérequis est de cumuler 12k points de gloire à la Curie (quêtes de livres) et d’avoir un personnage de niveau 95 minimum.
On achète les parchemins de quêtes auprès PNJ Shifty Steve (X523.Y158) à Dimension of Soul, à la sortie du village. Chaque parchemin coûte 6k po et doit être livré à un PNJ spécial sur les différentes maps disponibles, en fonction du set, pour débloquer une série de 5 quêtes (une par partie du set).
**SOMMAIRE**
→ Armures lourdes : Elemental Guardian / Bahemoth / Dragon Lord
→ Armures légères : Flame Cerberus / Evil Necromancer / Thunder Hound / Tempest Enchanter / Voodoo Leader
→ Robes de protection : Infernal King / Divine Lord / Spell Master
Pour obtenir les pièces de set « broken », il faut démanteler dans la boîte mystique les pièces de set gold qu’on peut loot dans les donjons HQ95. Les worldboss dont il est question sont ceux qui sont invoqués aléatoirement après avoir brisé le cristal dans ces mêmes donjons.
**Armure lourde : Awakened Elemental Guardian**
* * *
_Rendre le parchemin de quête au PNJ Harry à Tempest Cliff [Falaise des Grands Vents]._
**Effets du set éveillé**

• Effet 3 pièces : Résistances +5, AGI +70, BLOC +5%
• Effet 5 pièces : Dégâts subis -10%, ESQ +200, mal généré +5%. Chaque compétence active le statut « Elemental Guard » (dégâts subis -2%) pendant 5 secondes, cumulable 5 fois.
