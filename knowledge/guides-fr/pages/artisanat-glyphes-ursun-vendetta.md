# Artisanat : glyphes (ursun) (Vendetta)

> Source : `raw/guides-fr/2018/10/19/artisanat-glyphes-ursun-vendetta.html` — publié le 2018/10/19 (site WordPress edenfr.wordpress.com)

L’artisanat ursun est régulièrement remanié par les GM du serveur Vendetta, pour accompagner le rééquilibrage constant des classes. Ainsi certaines glyphes diffèrent aujourd’hui considérablement d’un serveur à l’autre, et il faut être vigilant sur la date de diffusion de l’information. Il est recommandé de _ne pas_ se baser sur le google doc des GS Vendetta, qui comporte de nombreuses approximations tant sur les compos que sur les effets des glyphes.
_Dernière mise à jour de cette page : 31/10/2018, avec Rubéole, Tiwaka et Yaxian._
