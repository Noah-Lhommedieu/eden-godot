## Découverte (à remonter — fichier hors périmètre)

`CollisionBuilder.Collect` inclut le Transform racine dans `rel` →
`body.Transform` local = objT·meshRel → colliders posés à **objT²**
(double transform — les 2 811 colliders actuels sont déportés ~2× la
position de l'objet). PropBatcher pose les siens correctement — les
props batchés bloquent réellement (mesuré via SpringArm caméra).
Correctif suggéré : exclure le transform du nœud racine dans
`Collect` (ou appeler `Collect` sur les enfants).
