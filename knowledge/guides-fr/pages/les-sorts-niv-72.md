# Les compétences de classe niv. 72

> Source : `raw/guides-fr/2017/05/29/les-sorts-niv-72.html` — publié le 2017/05/29 (site WordPress edenfr.wordpress.com)

Chaque classe, hormis le chevalier du chaos et le juge, dispose d’un sort d’attaque ou d’un buff spécifique que l’on peut acquérir au niveau de classe 72. Les parchemins s’échangent chacun contre 9.000 insignes de combat auprès du **PNJ Konice** de la **Vallée de Vulcain** (X:54 Y:114), vers la Tour de guet Gustgate. Ces sorts sont également disponibles pour le messie même s’ils n’ont pas été préalablement activés pour la classe de base.
