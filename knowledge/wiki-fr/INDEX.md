# Wiki Eden Eternal (fandom FR) — Index

Index des pages du **wiki fandom français** d'Eden Eternal (`raw/wiki-fr/`, 243 pages HTML, ère ~2012-2017).

Chaque page a été convertie en markdown dans `pages/` (texte, tableaux et listes conservés ; navigation et pied de page supprimés). Les images restent des URL distantes (`static.wikia.nocookie.net` — non téléchargées). Les liens internes `/fr/wiki/X` pointent vers les `.md` locaux quand la page existe dans le dump, sinon vers eden-eternal.fandom.com.

**Valeur principale** : les **noms FR officiels** (zones, donjons, boss, PNJ, quêtes, items, sorts) pour l'i18n — plus des tables uniques : `Classes`/`Tableau_des_classes` (prérequis par classe), `Les_Certificats` (combos), `Comparatif_des_compétences_raciales` + `Sorts_de_race_(par_classe)` (20 classes × 5 races), `Boss_de_Donjons` (~80 boss avec faiblesses), `Quêtes` (chapitres + succès FR + armes éveillées 65 / sets éveillés 70), `Quêtes_de_guilde` (~50 quêtes), `Montures` (liste complète par famille), `Géographie` (régions par niveau), `Ville_de_Guilde`, `Arène`, `Familiers`, `Décrypteur_de_Glyphes`, `Tissage_(Ezelins)`, `Trophées_obtenus_par_les_Boss_de_guildes`, la série didactique des Monts Calcaires (~15 quêtes chaînées avec dialogues) et ~20 quêtes Hautes-terres (56-60).

**Lacunes** : wiki arrêté vers 2017 — couvre ≤70-80, **rien niv. 76-90** ; tables de trophées 30-60 quasi vides ; élites rares non listés après Baie Bélouga ; sorts raciaux Ézelin absents ; plusieurs pages stubs/doublons et pages mal rangées (montures classées monstres, quêtes classées équipements) ; noms FR instables (Champignoïde/Champinoïde, Cristaux Asbi/Asbee…).

**Périmètre serveur** : notre serveur réplique l'Eden de base (contenu jusqu'au niveau 90). Ce wiki n'a **aucun contenu >90** (arrêté avant) — le seul piège est de ne pas confondre les armes/sets éveillés 65-80 (contenu de base, dans périmètre) avec l'éveil 95+ de Vendetta.
